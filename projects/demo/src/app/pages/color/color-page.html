A component declares that it is a layer, and its surface follows from the depth it sits at. Everything it draws on that surface it names from a palette of fixed steps.

--itx-surface is the background a component stands on. Its value comes from the element's depth. Add itx-layer to nest one step further from the page; nesting compounds.

Four tokens read the ladder from wherever they are used: --itx-surface, --itx-surface-above, --itx-surface-above-2 and --itx-surface-below. itx-sink nests a recess instead of a raise; itx-layer="2" pins a depth regardless of where the element sits.

Each layer's lightness is computed from six numbers per scheme, so one dial moves every layer at once. 

clamp(min, page + step × layer, max)

Every library selector is zero-specificity and sits inside the interop cascade layer, so any rule you write wins on contact.

Change one component

Set the component's own token. No layer block touches it.

--itx-dialog-background: var(--itx-role-background-interactive);

Change a role everywhere

Roles are declared once and inherit. Set one on any ancestor and everything below follows. 

--itx-role-edge: oklch(0.55 0.01 250);

Move every surface

Redeclare a surface value or a tint pack at the root. Retuning the ramp and retinting a subtree are the same act. 

--itx-ramp-dark-page: 0.20;
--itx-tint-dark: 0.006 250;

What gets overwritten

--itx-surface is written by the engine at every layer boundary, so a value set on an ancestor is replaced one layer down. Reach for a component's own token instead.

Three constraints to design around.

Margin shrinks with depth

A step is fixed while the surface climbs, so a pairing measured on the page reads closer once it is nested. Roles are placed to hold at the deepest layer: border sits at step 9 rather than 8 for this reason.

Chroma costs contrast

Two steps at the same lightness measure differently if one carries more chroma. A saturated family reaches its ceiling earlier, so a new family has to be checked rather than assumed. npm run lint measures every pairing in a browser and fails on a miss.

Colours are authored, not computed

Steps are literal values in styles/themes/protocol/ladder.css. Adding a family means writing fourteen values and running the checks. Nothing derives a palette from a seed at runtime.
