Mutually exclusive option group built on a native <fieldset>. Animated selection pill via CSS anchor positioning, roving tabindex keyboard model.

Each option is a <button interop-segment> carrying aria-pressed. The group is a stateful command group, not a form input — bind [value] and (valueChange) the way you would a two-way model.
