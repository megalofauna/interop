A collapsible hierarchy in one of two tiers. Bare [interop-tree] is a nested-list disclosure structure with real links and a natural tab order. interop-tree="select" is a role="tree" widget with one tab stop, roving focus and typeahead. Neither uses a virtualizer, so collapsed branches stay findable by find-in-page.

Everything below is collapsed, and every node is really there. Press Ctrl/Cmd+F and search for {{ buriedLabel }} — a leaf three levels down inside a collapsed branch. A browser supporting hidden="until-found" will find it, reveal the path, and scroll to it; the tree adopts that as real expansion. A virtualized tree cannot do this, because the node would not be in the document at all.
