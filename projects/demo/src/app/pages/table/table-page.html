itx-size sets the row height — 32 / 40 / 48 / 64px for sm / md / lg / xl, with 48px the default. The height is set by block-size on the row rather than by cell padding, so a single-line row snaps to the step and a wrapping cell grows past it. xl top-aligns its cells, on the assumption that a 64px row is there to hold two lines.

The scroll wrapper is on by default, so a table wider than its container overflows rather than crushing its columns. Naming it with scrollRegionLabel is what promotes the wrapper to an ARIA landmark — an unnamed region would only pollute the landmark list. sticky: true pins a column to the inline-start edge, and it gains a seam shadow once the wrapper has scrolled.
