Semantic list component for ul, ol, and dl. Accepts a [collection] input or static projected content.

      The template renders the contents of each item — interop-list owns the <li> itself, so supplying another one nests a list item inside a list item. Alongside $implicit the context carries index, first and last, which is what lets a row do more than print a string.
