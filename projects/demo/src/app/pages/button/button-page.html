A native button with a CSS-driven appearance, three availability states, and an optional set of activation guards — throttle, debounce, and reentrance.

Appearance is set through three attributes across two namespaces: interop-button="" for identity and variant, itx-size for size, and itx-radius for corner radius.

Five opt-in sizes on an 8-point grid — 24, 32, 40, 48, 64px — with md (40) the anchor. Each size pins its height; the block padding is derived from it, so the visible box lands at the stated height. The label stays 14px throughout: size changes the box, not the type. xl is the one exception, taking a 16px label. Side padding holds at 16px from md up and steps down at the two small sizes — 12px at sm, 8px at xs — because the block padding scales with the height, and a constant beside it inverts the padding box on a short button. Omit the attribute to retain the base size (md).

Seven opt-in radii, applied through itx-radius. This is a system-wide attribute, not a button-specific one — it resolves the semantic radius scale onto any element that opts in, so a button's corners align with the components around it. Omit the attribute to retain the theme default, which is none. full additionally switches corner-shape to round, since the default squircle cannot form a stadium.

A variant is a named bundle of CSS custom properties — nothing more. There is no variant registry and no component code to amend: define a selector, assign tokens, and that name becomes a variant. Any token left unset inherits from the base. The selector uses ~= (word match), so a button may carry more than one; the :where() wrapper keeps specificity at zero, so any default may be overridden from a consumer stylesheet.

interop-button-prefix and interop-button-suffix are marker directives — each adds a class and nothing else. Source order remains layout order, and the button's gap does the spacing; the slot rules only stop an addon from stretching and keep a 1em icon on the label's centre line. Neither sets aria-hidden, because a button's contents can be its accessible name. Mark a decorative addon aria-hidden yourself when a visible label is present; for an icon-only button give the host an aria-label and leave the icon alone.

A button communicates its availability through three distinct states, each producing a different set of attributes and a different relationship to the tab order. The choice among them is an accessibility decision, not merely a visual one.

The default. It sets the native disabled attribute, which browsers, form engines, and assistive technology all understand without further wiring. The button is removed from the tab order — appropriate when the action is structurally unavailable and its absence requires no explanation.

focusableWhenDisabled substitutes aria-disabled for the native attribute, keeping the button in the tab order. It suits a control a keyboard user should be able to reach in order to discover why it is unavailable — a submit button gated by form validity, for instance. Interaction remains blocked; the click is suppressed rather than the element withdrawn.

loading marks an operation in progress. It never applies the native disabled attribute: the button stays focusable, so a screen-reader user who reaches it mid-operation hears its busy state rather than silence. aria-busy is set, pointer interaction is suppressed, and the content is replaced by loadingText.

The guards live on InteropButtonActivation. Import it alongside InteropButton, pass a handler to [onActivate], and configure it with [activationOptions]. activationOptions accepts debounceMs, throttleMs, reentrant, and once.

Runs the handler at most once per window. The first click fires immediately; clicks within the window are dropped.

Runs the handler once, after clicks stop. Each click resets the timer; the handler fires after the window elapses with no further clicks.

Blocks overlapping runs of an async handler. While a run is in progress, further clicks are ignored until it settles, preventing duplicate submissions. This is the default (reentrant: false).
