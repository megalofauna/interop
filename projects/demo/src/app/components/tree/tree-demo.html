Tree

Also known as tree view, outline view, side navigation, nested navigation.

A tree is navigation through a hierarchy of pages. It is nested lists of links, with a <details> for each branch, and ul interop-tree on the outer list. It needs no script and no ARIA. Screen readers announce each branch as expanded or collapsed and each link's level from the nesting. Every link and every branch is its own Tab stop. The site navigation on this page is one.

Navigation

The current page has aria-current="page", which draws a bar, heavier text and a fill. Open the branch that holds it.

A branch with a page of its own

A branch is a label. Its <summary> opens and closes it, so it cannot also be a link. When a branch has a page of its own, list that page as its first child, as Overview is above. The dev audit warns about a link or a button inside a summary.

Find in page

Search this page for "Netlify" while Deploy is closed. The browser opens every branch above the match and scrolls to it.

One branch open at a time

Give the <details> of one level the same name. Opening one closes the others, with no script.

In Angular

ariaCurrentWhenActive sets aria-current="page" on the link to the current route.

When not to use it

A tree here is for navigation. A file browser where arrow keys move between items and select them is an ARIA tree, with one Tab stop and a different keyboard. Interop does not ship one. For one level of show and hide, use a plain <details>.
