Checkbox

Also known as check box, checks, checkboxes, tick box, tri-state or mixed checkbox.

A checkbox is a native checkbox inside a label interop-checkbox. The input draws the box and its mark. Each checkbox is its own yes or no, so it stands alone or in a group. It submits with its form and needs no script.

On its own

Long label

The box is centered on the first line of text, and the text wraps beside it. Links wrap with the text.

Disabled

A disabled fieldset disables every box in it, and its legend dims with them.

A group

A group is a fieldset interop-checkbox-group named by its legend. Boxes that share a name submit every checked value.

Templates

A checkbox group's look is a template, as a radio group's is. Interop ships two, each a pattern with its own page: cards and chips.

Select all, from a signal

Indeterminate is a property, not an attribute. In Angular, bind [indeterminate] on the input. Here the select-all box reads the same signal as the toppings.

Toppings

Select all, with bindSelectAll()

Without a model, bindSelectAll(parent) keeps the select-all box in step with the other boxes in its fieldset. It leaves disabled boxes alone, fires change on each box it changes, and follows a form reset. Give the select-all box no name, so it does not submit.

Choose at least one

required on a checkbox means that box must be checked, so it cannot express "at least one". Instead, set setCustomValidity() on the first box whenever the group changes. The browser then blocks submit and shows the message.

Sizes

The default size has no attribute. itx-size="lg" on the label makes the checkbox larger.

Custom tokens

Set --itx-checkbox-* properties on the label, or on a class that matches it. The mark is a mask, so --itx-checkbox-mark-mask-image swaps its shape.
