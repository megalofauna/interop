Page nav

Also known as table of contents, on this page, in-page navigation, scroll-spy, anchor navigation.

A page nav links to the sections of the page and marks the one in view. It is a <nav interop-page-nav> of plain links. The links scroll to their sections with no script, and the browser decides which section is current. This page shows both orientations at once; a real page uses one.

  • {{ section.label }}
    • }

Horizontal

The default. A bar of links on a rule, with a bar under the current link: the underscore look tabs wear. It sticks to the top of the page as the page scrolls, and casts a shadow once it sticks. A bar wider than its space scrolls sideways and keeps the current link in view.

Below a fixed header

Set --itx-page-nav-inset-block-start on :root. The bar sticks that far down, and a section scrolled to starts below the bar.

Vertical

itx-orientation="vertical" for a narrow column beside the content. The list is a tree, ul interop-tree, so sections nest. It is quieter than the site navigation: one rail along the list, a bar over the rail at the current section, and dim links that darken on hover. It sticks at the top of its column. A list taller than the window scrolls on its own; add interop-scroll-area for its edge shadows.

The current section

The list has scroll-target-group: auto, so each link to a section of this page is a scroll marker. The browser marks the link to the section in view with :target-current. A section is current from the moment its start reaches the top of the window, and the last one becomes current when the page reaches its end, however short it is.

Links to other pages are left alone, so a site navigation tree can hold the current page's sections as well.

Screen readers

The browser does not yet tell screen readers which link is current. bindTargetCurrent() gives that link aria-current="true", read from :target-current, so the highlight and what is announced agree. Nothing is announced while the page scrolls; the state is read when the user reaches the link.

Other browsers

Firefox and Safari have no :target-current. There bindTargetCurrent() chooses the current link itself: the last one whose section starts in the top half of the window, or the last one at the end of the page. The CSS draws aria-current="true" the same as :target-current.

In Angular

InteropPageNav binds the helper. With <base href="/">, a bare href="#install" points at the site root, so give the links routerLink and a fragment, and let the router scroll to anchors.

When not to use it

A page nav shows every section and reports position. To show one section and hide the others, use tabs. To move between pages, use the site navigation. A page with two or three short sections needs neither.
