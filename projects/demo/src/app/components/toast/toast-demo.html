Toast

Also known as snackbar, toast notification, notification.

A toast is a short message about something the user just did, shown in a corner of the window: "Message sent", "Link copied". It moves no focus. toast() writes it into the page's toast region and speaks it with ariaNotify(), so screen reader users hear it where they are.

A toast is easy to miss: it sits away from the work, and a screen magnifier may not show that corner. Show the result in the page where you can: a saved form says so next to its button, and an error goes next to its cause. Use a toast when there is nowhere in the page to say it.

The region

Put one region in the app shell. It is a manual popover, so it sits in the top layer over every other popover, and it is a landmark named Notifications, which screen readers list. It shows while it holds toasts and hides when the last one goes. InteropToasts binds it in Angular; elsewhere call bindToasts(region).

Show a toast

A toast stays until the user dismisses it with its button, or with Escape while focus is in it. When a toast that held focus goes, focus moves to the next toast, or back to where it was before.

Status

color sets an icon and the color of the start edge, so the status shows in a shape as well as a color. A danger toast is announced at high priority, which interrupts the screen reader; keep it for something the user must hear now.

An action

A toast can hold one button, such as Undo. Pressing it runs the action and dismisses the toast. Offer the same thing in the page as well: a toast is easy to miss, and a keyboard user has to find it. Here each jettisoned crate can also come back from the list.

    @for (crate of crates(); track crate) {
  • {{ crate }}
    • } @empty {
  • The hold is empty.

A timeout

With timeout, a toast leaves by itself, after at least 5 seconds. The time stops while the pointer is over the region, while focus is in it, and while the page is hidden. Use it only for a message that does not matter if it is missed. A danger toast and a toast with an action ignore it.

Inside a modal dialog

A modal dialog makes the rest of the page inert. A toast in the page's region still shows over the dialog, but nothing in it can be clicked or focused. So a dialog that raises toasts holds its own region, and toast() uses it while the dialog has focus.
