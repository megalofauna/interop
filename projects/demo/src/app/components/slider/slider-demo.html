Slider

Also known as range, range input, range slider.

A slider sets one value from a range when the range matters more than the exact number: volume, brightness, zoom. It is the native <input type="range">. The browser gives it the arrow keys, Page Up and Page Down, Home and End, dragging, a click anywhere on the track, form submission and right-to-left. Interop draws the track, the fill and the thumb, and the house focus ring.

For an exact number, use a text field: a slider is hard to set to one value. For a few named choices, use a radio group, which shows every option.

One value

Label it like any field. The thumb's box is 24 pixels, the smallest target WCAG allows, and the drawn circle sits inside it.

A value with a unit

format turns the number into words for screen readers, as aria-valuetext: "$200", not "200". Use it only when the number alone misleads. readout shows the same words beside the slider, hidden from screen readers because the slider already says its value.

Vertical

itx-orientation="vertical" stands it upright, with the minimum at the bottom. Arrow Up raises the value, and screen readers hear a vertical slider.

In a form

The slider submits its value under its name. Reset puts the thumb and the fill back.

Two values

A minimum and a maximum are two text fields in a fieldset, not a slider with two thumbs. People set exact numbers in fields faster and more reliably, and each field has its own label.
