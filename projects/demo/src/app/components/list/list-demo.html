List

Also known as numbered list, ordered list, process list.

A numbered list draws each number in a circle: outlined, or filled with the number reversed out. It is a native <ol> with interop-list="outlined" or interop-list="filled", and needs no script. The circles match the step indicator's.

Number a list only when the order matters, as GOV.UK advises: steps to follow, a ranking. For a task someone is part way through, use the step indicator instead. USWDS calls this look a process list, for high-level steps.

Your numbering holds

start, reversed and <li value> give the same numbers the browser would. One digit is a circle; two grow a pill.

role="list"

Drawing the numbers hides the browser's, and Safari then stops announcing the list or how many items it has, on purpose: most lists without markers are layout. role="list" puts it back. See Scott O'Hara on lists in Safari. The development audit flags a numbered list without it.

Bare

interop-list with no value draws nothing: the browser's numbers stay, and the list needs no role.
