Steps

Also known as stepper, step indicator, progress indicator, progress tracker, progress steps, wizard, multi-step form.

A process split into ordered steps has two parts: a step indicator that shows where you are, and the steps themselves. The indicator is an ordered list with the current step marked aria-current="step". It shows progress; it is not a control. If the sections can be visited in any order, use tabs instead. A +/- number control, which some systems call a stepper, is an input type="number".
