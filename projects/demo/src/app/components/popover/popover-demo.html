Popover

A popover is the platform's popover attribute with interop-popover styles. The button that opens it is its anchor. The browser opens it, closes it on Escape or a click outside, and tells assistive technology whether it is open. None of this needs script.

Opened by a button

popovertarget or command="toggle-popover" with commandfor.

Placement

--itx-popover-position-area takes any position-area value. A popover to the side moves its gap to --itx-popover-margin-inline.

Near an edge

A popover flips to the other side of its button when it does not fit.

Long content

A popover too tall for the window scrolls. With only text inside, tabindex="-1" and autofocus move focus into it when it opens, so the keyboard can scroll it. Escape returns focus to the button.
