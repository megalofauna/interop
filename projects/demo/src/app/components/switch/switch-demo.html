Switch

Also known as toggle, toggle switch, slide toggle, checkbox toggle, on/off switch.

A switch is a native checkbox with role="switch" inside a label interop-switch. The input draws the track and the thumb. Screen readers announce it as a switch that is on or off. It submits with its form like any checkbox, and needs no script.

On and off

Long label

The switch is centered on the first line of text, and the text wraps beside it. Links and other inline elements wrap with the text.

Disabled

A disabled fieldset disables its switches, and they show it with no binding. A group of switches is a checkbox group: each is its own yes or no.

In a form

Change the switches, then reset the form. The switches return to their initial state.

Bound to a signal

Bind [checked] and listen to (change) on the input.

Sizes

The default size has no attribute. itx-size="lg" on the label makes the switch larger.

Custom tokens

Set --itx-switch-* properties on the label, or on a class that matches it.
