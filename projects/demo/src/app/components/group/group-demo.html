Group

Also known as button group.

A group holds controls that belong together and gives them one name, which a screen reader says when focus enters. It lays them out in a row that wraps. It adds no keys: each control is still a Tab stop. For one Tab stop and arrow keys, use a toolbar. For one choice from several, use a segmented radio group.

A named group

role="group" and a name. Leave the group out when the buttons' own names already say what they are for.

A fieldset

The same layout around a form question, named by its legend.

Notifications

Attached

interop-group="attached" joins the buttons into one shape. They stay separate buttons, each with its own Tab stop and focus ring, so name each one for what it does. A split button is an attached group.
