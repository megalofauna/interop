Tooltip

A tooltip opens while the pointer rests on its trigger or the trigger has keyboard focus. Escape, blur and pressing the trigger close it. Touch never opens it: on a touch screen a label tooltip still names its button for screen readers, but a sighted user sees only the icon, so pick an icon whose meaning is clear without it.

Naming an icon button

With interop-tooltip="label" the tooltip is the button's name. The button needs no other.
