Tooltip

A tooltip opens while the pointer rests on its trigger or the trigger has keyboard focus. Escape, blur and pressing the trigger close it. Touch never opens it: on a touch screen a label tooltip still names its button for screen readers, but a sighted user sees only the icon, so pick an icon whose meaning is clear without it.

A tooltip is written in the markup: an element with interop-tooltip, popover="hint", role="tooltip" and an id. Its trigger names it in aria-labelledby or aria-describedby, so the trigger has its name before any script runs, and popover keeps the tooltip out of the page until it opens. Call bindTooltips() from interop once and it opens and closes every tooltip, including ones a framework adds or re-renders later.

Naming an icon button

With interop-tooltip="label" the tooltip is the button's name. The button needs no other.

Describing a button

With no value the tooltip describes a button that already has a name.

Near an edge

A tooltip moves below its trigger, or along it, to stay on screen.

Inside a popover

Escape closes the tooltip first, and the popover with a second press.

Timing

--itx-tooltip-interest-delay-start and --itx-tooltip-interest-delay-end set the delays. Set them on the tooltip. These open at once.
