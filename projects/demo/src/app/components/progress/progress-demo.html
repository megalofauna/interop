Progress

Also known as progress bar, progress indicator, loading bar.

A progress bar shows how far a task has got: an upload, a sync, an export. It is the native <progress>. The browser draws the fill from value and max and tells screen readers the percentage. Interop draws the same track as the slider, at the same sizes. It needs no script.

For a measurement in a range, such as storage used or battery level, use <meter>. For the steps of a form, use steps. For a wait of a second or two, use a button's busy state.

How far a task has got

Name it with a <label>, like a field: <progress> is a labelable element.

Sizes

itx-size is sm, lg or nothing for the default: 4, 6 and 8px thick, the slider's track at each size.

Words for the value

Screen readers say a percentage. When a count says more, add aria-valuetext: "3 of 7 files", not "43%". Any max works; there is no need to scale to 100.

Amount unknown

Leave value out and a band crosses the track. Removing the attribute is the only way back to this state. While a region waits for the result, give it aria-busy="true" and point its aria-describedby at the bar. Clear both when it loads.

Saying it is done

A bar that moves is silent in most screen readers. Say the milestones once, with announce(), and show them as text: done, failed. Never every step.
