Table

Also known as data table, table view.

A table holds data in rows and columns. It is the native <table> with interop-table, and you write it: a <caption> to name it, <th scope="col"> for column headers, and <th scope="row"> for the cell that names each row. Interop styles it. There is no script.

The table fills its container and its cells wrap. A table too wide for its container goes in a scroll area; the console says when one needs it.

A reference table

Row headers name each row, so a screen reader says which attribute a description belongs to. Rows in groups take one <tbody> per group, its first row a <th scope="rowgroup">: a group header labels every row in its <tbody>.

A data table

itx-numeric on a cell aligns it to the end with figures of equal width, so digits line up down a column. A <col> cannot set alignment, so each cell carries it. This table is wider than a phone, so it sits in a scroll area named by its caption, which the keyboard can reach while it overflows.

A narrow layout of your own

Interop's table stays a table at every width. To change how it looks when narrow, write the layout yourself on a wrapper with a container query. This one stacks each row into a card below 30rem. Drag the frame's corner to see it.

Rows take their height from the line height and the cell padding, so turning them into blocks undoes nothing. Table semantics survive display: block and grid on table parts in current browsers, so a screen reader still reads a table with headers.

@for (member of crew; track member.name) { }

Name Role Station Hours

What a narrow layout must keep

Keep Why
The caption and every header cell Hide the header row from view, not from the page: screen readers still announce each cell's column from it.
No display: contents on table parts It removes their table roles in every browser.
Labels that match the headers data-label repeats the header for the eye. Keep it out of the spoken text with / "", since the header is announced already.
The data a row compares Stacking loses side-by-side comparison. For data read down a column, a scroll area keeps it.
