Radio group

Also known as radio buttons, radios, radio button group, option buttons, choice group.

A radio group is a fieldset interop-radio-group of native radios that share a name. The shared name makes them one control: one is checked at a time, Tab reaches the group once, and the arrow keys move the choice. The legend names the group. Each label holds its radio and its text, and needs no attribute. None of this needs script.

Templates

A radio group's look is a template: you write what goes in each label, and its CSS lays it out. Interop ships interop-radio-group="cards", one template among any number. Under the template the group is the same radio group, with the same behavior, the same checked mark, focus ring and disabled state, and the same audit rules.

Cards

Each option is a card. The input names the option with aria-labelledby pointing at its title and describes it with aria-describedby, so a screen reader reads "Pro, radio button, 2 of 3" and then the details, not the whole card on every arrow press.

Plan @for (plan of plans; track plan.id) { }

Chips

interop-radio-group="chips" draws each option as a pill that sizes to its text and wraps. Use it for many short options. For a short row of equal options, use the segmented control.

Shirt size @for (size of sizes; track size) { }

Your own template

A template needs no API. This one adds a muted description under each option, in about five lines of the page's own CSS. Interop's rules have no specificity, so a class of yours always wins.

A template may A template must keep
Lay out the label any way: grid, card, row, tile The input inside its label, with a shared name
Decorate it: borders, fills, shadows, images A visible checked mark that does not rely on color
Put any inline content in the label: names, prices, badges, icons Inline content only: spans and other inline elements, no div, p, list or heading
Style states with label:has(> input:checked), :focus-visible and :disabled No button or other control inside the label
Hold links in the label, for short text such as terms Rich content split into a name and a description
