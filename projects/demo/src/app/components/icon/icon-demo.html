Icon

An icon is an <svg interop-icon> named after a registered icon. In Angular the InteropIcon component draws it; elsewhere, drawIcons(root) from interop draws every icon in root. Register the icons once, with registerIcons().

Named icons

Interop ships these Tabler icons. Register your own the same way.

@for (name of names; track name) { {{ name }} }

Sized by the text around it

Without a size, an icon is as tall as the text around it.

Size scale

itx-size picks a step: xs 12, sm 16, md 20, lg 24 and xl 32px. A button sets its icons to 16, 20 or 24px by its own size, and --itx-icon-size on any element sets every icon inside it.

Fixed size

size in pixels fixes an icon over everything else.

Labeled

An icon is hidden from assistive technology unless it has aria-label or aria-labelledby, which make it an image.

Your own SVG

Without name, an icon draws its own children.
