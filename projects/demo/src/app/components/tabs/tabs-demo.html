Tabs

Also known as tab list, tab group, tab strip, pivot.

Tabs show one of several sections at a time. You write the tab list and the panels, and each tab names its panel with aria-controls. bindTabs(root) from interop adds the keyboard, selection and panel hiding. In Angular the same markup binds itself: the InteropTabs directive from interop/tabs matches [interop-tabs]. To choose a value or a view of the same content, use a segmented control.

Sizes

Segmented

interop-tabs="segmented" gives tabs the segmented control's look. They are still tabs: each one shows a different section. To choose a value or a view of the same content, use the segmented control itself.

With icon, each tab is square and holds an icon; its name is visually hidden text.

Icons and counts

You own the buttons, so icons, badges and tooltips work as anywhere else. A count shows the number and speaks what it counts.

Manual activation

With activation: "manual", the arrow keys move focus and Enter or Space selects. In Angular, activation="manual" on the element.
