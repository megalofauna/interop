Tabs

Also known as tab list, tab group, tab strip, pivot.

Tabs show one of several sections at a time. You write the tab list and the panels, and each tab names its panel with aria-controls. Wrap them in <interop-tabs> and import interop/tabs once: the import defines the element, which adds the keyboard, selection and panel hiding wherever the markup appears, in any framework or none. To choose a value or a view of the same content, use a segmented control.

In a framework's template

Angular renders these tabs from a list. Adding or removing a tab needs no extra call: the element reconciles its own children, and a removed selected tab passes the selection to a neighbor. The template writes hidden="until-found" on every panel but the one shown at first, from a value that never changes, so Angular writes it once and the element owns it after that. The element also owns aria-selected; change the selection with select(). Angular needs CUSTOM_ELEMENTS_SCHEMA in the component that uses the element.

Sizes

itx-size is sm, lg or nothing.

Segmented

itx-variant="segmented" gives tabs the segmented control's look. They are still tabs: each one shows a different section. To choose a value or a view of the same content, use the segmented control itself.

With icon, each tab is square and holds an icon; its name is visually hidden text.

Icons and counts

You own the buttons, so icons, badges and tooltips work as anywhere else. A count shows the number and speaks what it counts.

Manual activation
