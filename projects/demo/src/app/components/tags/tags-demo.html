Tags

Also known as removable chips, input chips, tokens, pills, dismissible tags.

Tags are values the user can remove: applied filters, or the entries of a tag input. Each tag is its text and a button that removes it, named for the tag. A tag that cannot be removed is a badge. A chip you select is a checkbox or radio: see the chips template on the checkbox and radio group pages.

Removable tags

Remove a tag with the keyboard: focus moves to the tag now in its place, or the one before, or the heading when none are left. The removal is announced with ariaNotify(), so the page needs no live region.

Tag input

The tags come first, then the field: tested this way round, people found and removed tags most reliably. Enter adds a tag, and the addition is announced; a comma does not add one. A duplicate is rejected with a message the field shows and speaks. The datalist offers suggestions. Each tag holds a hidden input, so the values submit with the form, and the field is required until there is at least one.

Press Enter to add a skill. Backspace in the empty field moves to the last one
