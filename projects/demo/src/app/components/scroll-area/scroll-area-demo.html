Scroll area

A scroll area shows an inner shadow at each edge with content beyond it. The shadow darkens as more content is hidden on that side and fades as the last of it comes into view. While it overflows and nothing inside can take focus, the area takes focus itself, so the keyboard can scroll it.

bindScrollArea(area) from interop manages that focus; in Angular, InteropScrollArea matches [interop-scroll-area]. Give the area a size to scroll at: the examples' CSS does.

Firefox does not support scroll-driven animations yet, so it shows no shadows. Everything else works there.

Text

Named by its heading with aria-labelledby, so it is a group with that name.

Controls

The buttons take focus, so the area does not. Tabbing to a button scrolls it into view.
