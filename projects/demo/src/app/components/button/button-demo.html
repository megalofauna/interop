Split button

Also known as combo button, button with menu.

A split button is an action and, joined to it, a button that opens other choices for the same action. It is two buttons in an attached group, and a popover. The browser opens and closes the popover, says whether it is open, and returns focus to the button on Escape. It needs no script.

Each half is a Tab stop with its own focus ring. Name the second button for what it offers, such as "More save options". A screen reader hears two buttons, so "Open menu", or a copy of the first button's name, says nothing about how they relate. The dev audit warns about both.

Use one when one action is clearly the usual choice. Otherwise, show the choices as separate buttons, or put them all behind one button: in testing, most people press only the larger half.
