Button

Sizes

itx-size is sm, lg or nothing for the default: 32, 40 and 56px tall.

With an icon

An icon in a button is 16, 20 or 24px at the small, default and large sizes.

Icon buttons

interop-button="icon" makes a button square at every size, with the icon centered. Name it with aria-label, visually hidden text or a label tooltip. The dev audit warns when a button shows only an icon and has no name.

An icon's own itx-size overrides the button's: here the default button holds an xs and an lg icon.

Radius

Each step is a multiple of the house radius, 8px by default: none, half, once, twice and three times, or a pill. No attribute is the house radius.

Disabled

disabled takes the button out of the Tab order. aria-disabled="true" keeps it focusable, so a screen reader user can still find it and hear why it is unavailable, and guardActivation(), started once by the app, cancels its clicks.

Pressed

A button that stays on, such as Bold, sets aria-pressed. Its name does not change with its state.

Busy

While its work runs, a button sets aria-busy="true" and shows a spinner. Press Busy to switch it.

Pending action

[pendingAction] takes a function that returns a promise. The button is busy until it settles, and ignores presses meanwhile. bindPendingAction() does the same without Angular.
