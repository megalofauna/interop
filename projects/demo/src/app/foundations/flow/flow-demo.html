Flow

Flow spaces the blocks of running content: an article, a docs page, a changelog. It is one attribute on the container, and this page is written with it.

Space goes above a block and only between siblings, so the first block has none above it and the last has none below. The container's own padding decides its edges.

Install

Flow ships in interop.css. Put itx-flow on the element that holds the content.

Only direct children are spaced. A component inside the flow keeps its own layout, and spaces its parts with gap.

What it needs

  • Interop's stylesheet, interop.css.
  • The reset, if the page should also lose the browser's margins outside flow containers.
    • Inside a flow container, the browser's margins are removed anyway.
    • Outside, they stay until the reset removes them.
  • Nothing else: there is no script.

The spaces

Each space is a token on the container. Blocks sit 24px apart; tables, figures and code stand further from the text around them. Running text reads at 16/28px.

Between Space Token
Blocks 24px --itx-flow-space
A table, figure, code block or media 40px --itx-flow-space-figure
An hr 64px --itx-flow-space-hr
Before / after h2 64 / 20px --itx-flow-space-h2[-after]
Before / after h3 48 / 16px --itx-flow-space-h3[-after]
Before / after h4 to h6 32 / 12px --itx-flow-space-h4[-after]
List items 12px --itx-flow-space-li

Retune a space on the container:

Headings

A heading has more space above it than below, so it reads as the start of what follows. The space after a heading wins over the space a table or figure asks for.

Trimmed to the letters

Headings are trimmed to their cap height and baseline with text-box. The space around a heading is measured from its letters, not from the leading of its line box.

Lists

List items sit 12px apart. Lists with a role are left alone: Interop's own lists carry role="list" and keep their layout.

Margin describes a relationship between siblings, so style the context, not the element.

Why space only goes above

A margin below the last block would add to the container's padding. With space only above and only between siblings, nothing trails, and margins never collapse unexpectedly.
