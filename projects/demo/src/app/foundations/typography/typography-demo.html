Typography

A scale sized for documentation. Headings step down quickly to body size, and every size is fixed. Each heading role has its own weight token, --itx-font-weight-h1 to -h5, so a heading can grow heavier as it grows smaller. Each sample shows its size, line height and weight.

@for (role of roles; track role; let i = $index) {
itx-font="{{ role }}" {{ measures()[i] }}
The quick brown fox jumps over the lazy dog
}

Inline elements

The reset styles the elements inside running text. Their tokens live in typography.css and code.css.

Run npm install interop, then import interop.css once. Open the command palette with Ctrl + K, or press / to search.

Read the WCAG understanding documents before you change a color. The WCAG asks for 4.5:1 for body text and 3:1 for large text1. Water is H2O.

1. Large text is 24px, or 18.66px bold.
