App shell

An app's primary navigation shows as a sidebar when its container is wide enough, and goes behind a Menu button when it is not. It is a grid and a container query over platform elements. There are two ways to hide the navigation when narrow; the wide layout is the same in both.

Concern Disclosure (default) Drawer
Narrow The navigation opens in the page and pushes the content down The navigation slides over the page, with a backdrop
Built from <details> with its <summary> as the button <nav popover> with interop-popover="drawer", and a command="toggle-popover" button
Script None bindDrawer(), about 30 lines
Keyboard The summary opens and closes it; focus stays in page order Opening moves focus to the current link. Escape, a click outside, following a link, or tabbing out closes it, and focus never lands on the page behind it
Announced "Menu, button, collapsed" or "expanded" "Menu, button, collapsed" or "expanded"

Drawer

A popover is not modal, so on its own the keyboard could move on to page content hidden behind it. bindDrawer() closes the drawer when focus leaves it. The browser does the rest: Escape and a click outside close it, and closing returns focus to the Menu button.
