Command palette Pattern

Also known as go to page, quick open, ⌘K search.

A pattern, built from a dialog and a field, with bindFilter() and bindShortcut().

interop-dialog="palette" is a search field over a list of links, in a dialog near the top of the window. Only the list scrolls, and the key hints sit below it. Typing hides the links that do not match, and the count is announced when typing pauses. Arrow Down moves to the first link and Enter follows it. The first Escape clears the field and the second closes the dialog. Each result is a link, so it opens in a new tab and works with any screen reader, on a phone too.

InteropShortcut gives the button a key, and the key clicks the button. It writes the platform's key into the empty <kbd> and sets aria-keyshortcuts. The Search button at the top of this site is this example with ⌘K or Ctrl K.
