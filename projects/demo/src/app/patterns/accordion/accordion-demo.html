Accordion Pattern

Also known as expansion panels, collapsible sections.

A pattern, built from disclosures in the row look.

An accordion is a stack of disclosures under a heading, each opening its own section. Give them one name and the browser keeps one open at a time: opening a section closes the one before. Without a name, any number stay open. It needs no script.

Use one where readers need only some sections, such as answers to separate questions. When they need most of the content, a long page with headings is easier to read and search: GOV.UK uses accordions only where research shows they help, and Nielsen Norman Group found they add work on desktop.

One open at a time

Each summary holds a heading, so readers can move between sections by heading. Screen reader support for a heading inside a summary is partial: some read it as the summary's text only. The section's heading above the stack names the group, since a shared name adds none.

Any number open

Leave name out when readers compare sections, such as settings.
