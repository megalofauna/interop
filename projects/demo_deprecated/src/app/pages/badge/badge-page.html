Overlay notification counter for buttons, avatars, and any interactive element. Placement is CSS Anchor Positioning — the indicator is position: fixed, so it escapes every overflow context without a line of layout JavaScript.

The visible indicator is aria-hidden — a number on its own means nothing. A visually-hidden sibling carries [accessibleLabel] and is wired to the first interactive child via aria-describedby, so always provide one. Omitting it logs a dev-mode warning.

The indicator is centred on the named corner, half in and half out. Set --itx-badge-offset to a positive length to push it further out, or a negative one to tuck it inside — see CSS tokens.

Proportions and paint follow IBM Carbon's badge-indicator: a 16px count bubble, an 8px dot, both fully round, both painted from the status palette's --itx-role-background-danger — so switching itx-status-palette reskins the badge with everything else. Badge is styled from its own component stylesheet rather than the foundation/theme split, so these tokens are read with inline fallbacks; set them on any ancestor.
