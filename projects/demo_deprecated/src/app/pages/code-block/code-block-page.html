Tabbed code viewer with copy, optional line numbers, and a word-wrap toggle. Assembles interop-code-renderer, the toolbar rig, and interop-button into one accessible surface.

Every example on this site is rendered by this component, including the ones below.

Both are opt-in. Line numbers earn their space in a long excerpt and waste it in a three-line one; wrapping is off by default so a long line scrolls instead of reflowing the block.
